## 塔塔 AI 客户端使用教程

适用版本：Windows x64 客户端 1.1.6。

### 1. 下载与打开
- [下载 EXE](https://github.com/1034142730/tata_ai/releases/download/1.1.6/TataAI-Client-1.1.6-win-x64.exe)：下载后右击管理员方式运行。
- [下载 ZIP](https://github.com/1034142730/tata_ai/releases/download/1.1.6/TataAI-Client-1.1.6-win-x64.zip)：解压到自己的文件夹，再运行其中的 EXE。
- 1.1.5 已停止提供下载。不要同时运行多个版本。

### 2. 首次注册
向管理员领取一次性邀请码，在欢迎页展开「注册账号或登录」：
1. 填写账号，例如「一路向北」或「tata_user01」。
2. 账号支持 1–20 位中文、英文字母、数字、下划线、连字符；不能填写包含 @ 或点号的邮箱。
3. 设置 8–20 位密码，填写邀请码。
4. 点击「使用邀请码注册」，成功后会自动尝试登录。

邀请码只用于注册，不等于额度兑换码。邀请码可能被禁用、已使用或过期，遇到提示请联系管理员。注册成功但登录失败时，使用已有账号登录，不要反复注册。

### 3. 已有账号登录
填写账号和密码，点击「登录已有账号」。登录无需邀请码。
正常保存后，再次打开客户端会显示「正在恢复登录」，成功后进入主页。连接失败可点击「重新连接」；如仍失败，可用原账号密码登录。

### 4. 兑换额度
向管理员领取额度兑换码。登录后进入「充值续费」，填写完整兑换码并提交，再查看余额是否到账。
例如备注为「50刀」的兑换码表示管理员设置的额度说明，实际到账以系统结果为准。
如提示已兑换或充值状态待确认，先刷新余额和充值记录，再联系管理员核对，不要反复提交。

### 5. 查询额度与使用记录
登录后在主页查看余额，并通过使用记录查看消费明细。网络异常时稍后刷新。
展示金额以系统实际返回的数据为准。

### 6. 使用已有 TATA- 卡密
持有管理员发放的激活卡密时，可在欢迎页粘贴完整的 TATA- 开头卡密，点击「立即激活」。
程序会依次验证卡密、登录账号、配置 Claude Desktop，并按卡密内容处理额度。若提示充值待核对，请先查余额。
邀请码、兑换码和 TATA- 卡密是不同用途的凭据，请填入各自的输入框。

### 7. Claude Desktop
需要使用 Claude Desktop 时，请先安装官方程序，客户端可通过「重新检测」检查是否安装。
账号注册和登录不代表已完成 Claude Desktop 配置；若尚未配置，请按客户端配置入口的提示操作，或联系管理员取得配置所需信息。

### 8. 更新客户端
启动时客户端会检查后台发布的版本：
- 可选更新：可以先继续使用，再选择更新。
- 强制更新：检测到新版本后，需完成更新才能继续操作。
点击更新按钮后等待下载、校验和打开新版本。失败时点击「重试」，或从本仓库 Releases 手动下载。
便携版请将新 EXE 保存在固定文件夹，之后从新文件打开。

### 9. 常见问题
| 提示 | 处理方式 |
| --- | --- |
| 账号或密码格式不符 | 检查上述长度规则；账号不要含空格、@ 或点号 |
| 用户名已存在 | 登录已有账号，或换一个用户名注册 |
| 邀请码无效、已使用或已过期 | 联系管理员核对或补发 |
| 注册服务暂未配置／接口不存在 | 联系管理员检查服务部署 |
| 未检测到 Claude Desktop | 安装官方程序后点击重新检测 |
| 更新下载失败 | 检查网络是否能访问 GitHub，重试或手动下载 |
| 更新包校验失败 | 重新下载；仍失败请联系管理员 |
| 登录恢复失败 | 重新连接，或用原账号密码登录 |

向管理员反馈时请提供客户端版本、错误提示和发生时间。截图请遮住密码、邀请码、兑换码和完整卡密。
